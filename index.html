Projects

Microstructure Lab: Liquidity, Spreads & Information-Based Trading

Tools: Python, Streamlit, yfinance, Plotly, Render · GitHub

Interactive laboratory for market microstructure. Estimates the Roll (1984) spread proxy from return autocovariance (with honest failure diagnostics), simulates the Glosten–Milgrom adverse-selection model, demonstrates synthetic market impact, and compares liquidity proxies across US and Indian equities/ETFs using Yahoo Finance data. Explicitly separates real data from simulations.

MarketSelect: EV-Charging Market Entry

Tools: Python, PuLP, Streamlit, Render, Statista · GitHub · Live

A decision app for public EV-charging market entry. It takes Statista revenue forecasts for 9 European countries and solves a mixed-integer program for which markets to enter and how to split a fixed budget.
