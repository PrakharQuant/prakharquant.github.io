Projects

Option Engine Room: Black-Scholes, Merton, Heston & SABR

Tools: Python, NumPy, SciPy, Plotly.js, MkDocs Material, KaTeX · GitHub · Live

Interactive teaching site for four option-pricing models through an “engine” mental model. Each term in the SDE is an engine (Steady Drift, Stock Noise, Jump, Rubber-band, Vol Noise, Linkage, Scaling gear). Covers closed-form and Monte Carlo pricing, coloured KaTeX equations, term-by-term tables, client-side Plotly simulators, storm persistence, and a smile lab. Validated against textbook values (BS 10.4506, Merton λ=0 recovers BS, Heston CF vs MC, SABR limits).

Arrow-Debreu Securities & the Fundamental Theorem of Asset Pricing

Tools: HTML, CSS, JavaScript, Plotly.js, KaTeX · GitHub · Live

Graduate-level interactive teaching site for Arrow-Debreu securities, state-space geometry, complete vs incomplete markets, and the Fundamental Theorem of Asset Pricing (FTAP). Pure math core with linear algebra, state prices, replication and SDF; 5-step pedagogical modules (intuition, predict, visual, table, self-check) plus explicit arbitrage detection and canonical market verification.

STOCHLAB: Exploring the Mathematics of Financial Uncertainty

Tools: React, TypeScript, Vite, Plotly.js, KaTeX, Tailwind · GitHub · Live

Interactive computational laboratory for stochastic interest rates and stochastic volatility. Implements the Vasicek model (exact discretisation, conditional moments, zero-coupon bond pricing, yield curves) and the Heston model (correlated Brownian motions, full-truncation Euler scheme, characteristic-function European option pricing, implied-volatility smile). Users can modify parameters, simulate paths, and compare theoretical results with Monte Carlo.

Microstructure Lab: Liquidity, Spreads & Information-Based Trading

Tools: Python, Streamlit, yfinance, Plotly, Render · GitHub

Interactive laboratory for market microstructure. Estimates the Roll (1984) spread proxy from return autocovariance (with honest failure diagnostics), simulates the Glosten–Milgrom adverse-selection model, demonstrates synthetic market impact, and compares liquidity proxies across US and Indian equities/ETFs using Yahoo Finance data. Explicitly separates real data from simulations.

MarketSelect: EV-Charging Market Entry

Tools: Python, PuLP, Streamlit, Render, Statista · GitHub · Live

A decision app for public EV-charging market entry. It takes Statista revenue forecasts for 9 European countries and solves a mixed-integer program for which markets to enter and how to split a fixed budget.

MacroTab: Macro Regime Map and Crisis Radar

Tools: Python, Streamlit, Global Macro Database · GitHub · Live

Turns 60+ years of country-level macro data from Prof. Karsten Müller's Global Macro Database into a research workflow: historical-only K-means regime discovery, next-year crisis scoring with temporal out-of-sample testing, country ranking across growth, inflation, debt, current account and unemployment, and illustrative macro tilts. Users upload data fetched from globalmacrodata.com.
